# 🎓 SYSU Auto Evaluation | 中山大学自动评教脚本

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Tampermonkey](https://img.shields.io/badge/Tampermonkey-Supported-green.svg)](#)

这是一个专为 **中山大学教务系统** 打造的高效、全自动学生评教脚本。基于最新的 Vue + iView 框架进行了全面重构，完美兼容当前教务系统环境。

---

## ✨ 核心特性

- **📂 跨类别全自动遍历**：
  脚本支持从“一级任务分类页”开始，逐个点击未完成的类别，进入“二级课程列表页”，对所有未评教的老师进行填答。单类别评教结束后，自动点击“返回”退回上一级，并继续评教下一个类别，直至全校所有评教任务完全结束。
- **📊 动态表头数据比对**：
  自动扫描表格列头以定位“总评数”与“已评数”的位置，智能判断该分类或课程是否已完成评教，避免重复评教或死循环。
- **📝 iView 单选框与矩阵行自动填答**：
  支持单选框组（Radio Group）与表格矩阵单选行的自动定位，默认勾选最右侧最优秀的选项。
- **🎚️ Vue Slider 滑动题完美解决**：
  针对 iView 自定义滑动条（Slider）组件进行了深度穿透。优先通过 `unsafeWindow` 直接修改 Vue 内部状态（currentValue），并派发 input 和 change 事件，备用方案则模拟鼠标按下和抬起事件拉满滑块，确保表单顺利提交。
- **✍️ 主观题自动填充**：
  自动为文本框（textarea）填充正面的教师评语，防止因主观题未填而无法提交表单。
- **🖥️ 独立悬浮控制面板**：
  在顶级窗口中渲染一个精致的控制面板，支持自由拖拽、最小化，并实时显示已评教的课程门数。
- **🛡️ 30秒无响应超时防死锁**：
  基于 Tampermonkey 全局共享存储（GM API）监控活跃时间。一旦检测到卡死或加载超时超过 30 秒，脚本将自动停止运行并向用户发出警报，绝不挂起浏览器。

## 🚀 安装指南

1. **安装脚本管理器**：
   在浏览器中安装 [Tampermonkey](https://www.tampermonkey.net/) (油猴) 插件。
2. **导入脚本**：
   - 打开 Tampermonkey 的控制台，点击“添加新脚本”。
   - 将 [SYSU-Auto-Evaluation.js](./SYSU-Auto-Evaluation.js) 的全部内容复制并粘贴覆盖到编辑器中。
   - 点击“保存” (Ctrl+S) 启用脚本。

---

## 💡 使用方法

1. 登录 **中山大学教务系统**，并进入**学生评教管理**页面。
2. 页面加载完成后，右上角会出现绿色的 **🎓 自动评教** 悬浮控制面板。
3. 确保页面处于“一级评教分类任务页”后，点击悬浮窗中的 **“开始评教”** 按钮。
4. 脚本将自动接管浏览器并以秒级速度快速完成全校课程的评教。评教完成后，系统将弹出“评教已完成”的成功提示。
